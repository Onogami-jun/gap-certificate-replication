# Replication package

This archive accompanies the manuscript *Optimality gaps do not certify commitment in
freight operations*. Every number in the paper is generated by a script in this archive
from an input in this archive; the manuscript's section 9 names each pair.

## Environment

Python 3.11 with numpy, pandas, scipy (HiGHS branch-and-bound) and matplotlib.
A local Ollama server hosting `qwen2.5:7b` and `mistral:7b` is needed only to re-generate
the language-model candidates. The archived candidate files make every reported number
reproducible without it.

## Where to start

| script | what it does |
|---|---|
| `replication_check.py` | re-derives the headline numbers from the archived CSVs and prints one pass/fail line per check |
| `screen_pairwise.py` | recomputes the dropped-versus-kept comparison of section 5.6 (Fisher exact test, risk ratio) |
| `screen_ci.py` | Wilson and bootstrap intervals for the screen rule |

## Data notes

* `llm_slot_candidates.csv` (214 recorded calls, 163 capacity-feasible) and
  `llm_bunker_candidates.csv` (179 parsed plans) are the candidate archives behind every
  maritime statistic.
* `brent_raw.txt` is the FRED series `DCOILBRENTEU`, 715 daily observations from
  2 January 2024 to 27 October 2026. It is shipped so that the distribution can be
  recomputed without network access.
* The booking book of section 5.7 is synthetic and is generated by `real_case.py`.
* Local sampling is not bit-reproducible at a fixed seed. The archived candidate files
  are the source of truth; the paper reports the between-generation spread rather than
  claiming exact reproduction.
* Seeds: 20261028 for the bootstrap, 201-220 for the tie pools.
